# PIT RATING — логотип (вариант C «Шевроны ранга», утверждён 18.10.2026)

Знак: три шеврона ранга — уровни бойца. Верхний — полный цвет, средний 60 %, нижний 30 % (уровень растёт вверх).
Шрифт: Unbounded (PIT — 800, RATING — 400 с разрядкой на ширину PIT, дескриптор — 400). В SVG текст переведён в кривые.

| Цвет | HEX | Где |
|---|---|---|
| Золото | `#e8c35a` | знак и RATING на тёмном |
| Тёмное золото | `#9a7419` | верхний шеврон и RATING на светлом |
| Ink | `#15171b` | текст и нижние шевроны на светлом |
| Paper | `#f4f1ea` | PIT на тёмном |
| Фон | `#0e1014` / `#111418` | тёмные подложки, иконка |

Файлы:
- `svg/pit-logo-horizontal-*.svg` — основной (on-dark, on-light, white, black)
- `svg/pit-logo-full-*.svg` — с дескриптором PERFORMANCE INDEX OF TRAINING
- `svg/pit-logo-line-*.svg` — в одну строку (шапки сайтов и экранов, подвалы)
- `svg/pit-logo-stacked-*.svg` — вертикальный
- `svg/pit-mark-*.svg` — только знак; `pit-mark-gold-solid.svg` — без прозрачности (вышивка, гравировка, печать в 1 цвет); `favicon.svg`
- `png/app-icon.png` 1024, `png/avatar-gold.png` / `avatar-dark.png` 1080 (Instagram/Telegram), `png/apple-touch-icon.png` 180, `png/favicon-32.png`, `favicon-16.png`, PNG основных версий
