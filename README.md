# PIT RATING — демо

**PIT — Performance Index of Training · The Fighter Rating**

Интерактивное демо системы для залов единоборств: экраны зала (PIT Arena), кабинет тренера (PIT CRM), приложение бойца (My PIT) и рейтинг бойца PIT.
Данные генерирует симулятор (DEMO), реальные датчики не нужны.
